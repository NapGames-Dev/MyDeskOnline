Configuration et sauvegarde

Sélectionnez un dossier local pour enregistrer vos données ou indiquez un chemin manuel. Les données sont également conservées dans votre navigateur pour un accès rapide.

    Synchronisation entre appareils

    Synchronisez vos données entre votre téléphone et vos ordinateurs grâce à un Gist privé sur votre compte GitHub (gratuit).

    1. Créez un token GitHub avec uniquement la permission « gist ».
    2. Collez-le ci-dessous puis cliquez sur « Connecter ».
    3. Répétez sur chaque appareil avec le même token.
